# v5 Screener Ticker Linkage 독립 UX/IA 비평 및 의사 결정서

> **문서 상태**: 비평 단계 (Divergent Review)  
> **대상 범위**: 스크리너 내 종목 티커(`/stock`) 엔티티 링크 제공 방식 검증  
> **검토 목적**: "행 클릭(Row Click)"의 상세 토글 기능과 "티커 클릭(Ticker Link)"의 상세 페이지 점프 간의 상호작용 충돌(Double Affordance) 방지 방안 정의  

---

## 1. 핵심 쟁점 및 리스크 비교 (Tension Matrix)

스크리너 테이블 내에서 티커에 직접적인 주식 상세(`/stock/[ticker]`) 이동 링크를 심을지 여부에 대한 3가지 설계안의 장단점 비교입니다.

| 설계안 | 상호작용 방식 | 장점 (Pros) | 치명적 위험 (Cons) |
| :--- | :--- | :--- | :--- |
| **안 1. 행 클릭 전용**<br>(현행 유지) | 티커 셀을 링크화하지 않고, 행 클릭 시 인페이지 디테일 패널만 확장. | Clickable-Excel 가드레일을 완벽 준수하며 모바일 오클릭이 0%로 수렴함. | 사용자가 관심 종목의 전체 상세 분석 페이지(`/stock`)로 넘어가는 이동 경로가 너무 길어짐. |
| **안 2. 티커 인라인 링크**<br>(텍스트/칩 적용) | 티커 텍스트 전체 또는 `TickerChip`을 셀에 직접 렌더링하여 클릭 시 `/stock` 이동. | 1-Click 만으로 언제 어디서든 주식 상세로 갈 수 있어 엔티티 일관성이 가장 높음. | **더블 어포던스 붕괴**: 모바일에서 행 스크롤 또는 상세 열기 터치 도중 강제로 페이지 이탈 및 오클릭 지옥 유발. |
| **안 3. 간접 엔티티 렌더**<br>(**권장안**) | 행 클릭으로 디테일 패널을 먼저 확장한 뒤, **그 패널 내부에서 큼직한 `[분석 전체 보기 →]` 링크 제공**. | 두 액션 간 터치 타깃 충돌을 원천 차단하면서도, 관심 종목의 상세 분석 진입로를 안전하게 보장. | 즉각적인 상세 분석 이동에 1-Click의 추가 탐색 허들(2-Hop)이 필요함. |

---

## 2. 권장 안 및 UX 비평 논거 (Recommendation & Ruling)

독립적인 UX 비평으로서, **[안 3. 간접 엔티티 렌더링 (Row-Click to Detail Panel, with in-panel /stock Bridge Link)]** 방식을 전적으로 권장합니다.

### 1) 더블 어포던스(Double Affordance)는 인지 부하의 주범입니다.
- 단일 테이블 행 내부에서 특정 텍스트 셀만 다른 라우팅 경로를 유도(티커 누르면 외부 페이지로, 다른 셀 영역을 누르면 인라인 확장으로)하는 설계는 사용자의 클릭 대상에 대한 예측 가능성을 훼손합니다.
- 특히 모바일 뷰포트에서는 화면을 아래로 스크롤하는 드래그 제스처가 테이블의 '티커' 영역을 스칠 때 의도치 않게 주식 상세 페이지로 점프하여 세션 맥락이 끊기는 최악의 사용성을 유발합니다.

### 2) 스크리너의 핵심 사용자 맥락(User Context)은 '스캔 및 필터링'입니다.
- 스크리너에 진입한 사용자는 수십 개의 종목을 "빠르게 요약 비교"하고 필터링하는 것이 1차적 목표입니다.
- 바로 정밀 종목 상세 분석(`/stock`) 페이지로 뛰어드는 것은 2차적인 의사결정 단계이므로, '행 클릭 -> 디테일 확장 -> 상세 페이지 진입'의 **점진적 노출(Progressive Disclosure)** 설계가 멘탈 모델과 사용자 의도적 흐름에 완벽하게 일치합니다.

---

## 3. 타협안 제안 (Alternative: 하이브리드 가이딩)

만약 2-Hop 탐색 경로를 극도로 싫어하는 전업 투자자(Power User)를 위한 1-Click 점프를 반드시 제공해야 한다면, 다음과 같은 인터랙션 격리 가이드라인을 엄격하게 적용해야 합니다.

- **텍스트 클릭이 아닌 '아웃링크 전용 아이콘' 독립 분리**:
  - `AAPL` 텍스트 자체는 링크가 아니며 행 클릭 상세 토글에 기여합니다.
  - 티커 텍스트 우측 끝에 아주 작고 연한 **`[ ↗ ]` (External Link Icon)**을 별도의 인라인 버튼으로 두고, 이 영역만 `onClick={(e) => { e.stopPropagation(); ... }}` 처리를 하여 물리적인 터치 범위를 완전히 격리합니다.
  - 마우스 호버 시에도 행 전체에는 배경색 변화가 일어나는 반면, `[ ↗ ]` 아이콘 위에 롤오버될 때만 툴팁(`"AAPL 분석 페이지로 바로 가기"`)과 밑줄이 생겨 어포던스를 정밀 분할합니다.

---

## 4. 최종 승격 게이트 조건 (Rollout Gate for Screener Linkage)

- [ ] **이벤트 버블링 차단**: 티커 상세 링크나 아웃링크 버튼 클릭 시 행 전체 클릭 이벤트(`openDetailPanel`)가 격리 차단되어 작동하는지 통합 테스트 통과.
- [ ] **모바일 탭 격리 영역 검증**: 스크리너 테이블 내 독립 링크 탑재 시, 모바일 해상도에서 터치 오발률이 5% 미만임을 사용자 시뮬레이션으로 확인할 것.
- [ ] **디테일 브릿지 일치**: 스크리너 상세 확장 패널 헤더의 티커 명칭에 `/stock`으로 넘어가는 큼직한 `TickerChip`이 정상 탑재될 것.
