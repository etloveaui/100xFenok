2. Component surface

<SignalHelpPopover
  signal="profitability"        // keyof FenokSignalsSummaryRecord
  trigger={"icon" | "label"}    // icon button or whole label row
  placement={"auto" | "top" | "bottom"}
/>
  • Trigger: small circular “?” icon next to the signal label (same pattern as MetricHelp, but tokenized).
  • Anchor: popover is positioned relative to the trigger; auto-flips if it would overflow viewport.
  • Content: signal label + current score/direction, one-sentence interpretation, 4-band 0–100 scale table, disclaimer footer.
  • Scale copy: 0–40 위약, 41–60 중립, 61–80 우호, 81–100 강함 (signal-specific labels configurable).
  • Accessibility: aria-expanded, aria-controls, focus trap, Escape to close, click-outside to close, return focus to trigger.
  • Token rule: only --c-* CSS vars; no named Tailwind colors in W2-scoped files.
  • Extension: config-driven signal registry makes adding v0.2 axes a data change, not markup change.

3. Files / data flow

  • src/components/screener/FenokSignalHelpPopover.tsx — popover component + positioning hook.
  • src/lib/fenok-signals/signal-help-config.ts — registry of signal metadata (label, interpretation, scale labels, direction map).
  • Wired from FenokSignalLensCard (full detail) and StockDetailPanel (screener expanded row) via the existing FenokSignalsSummaryRecord.
